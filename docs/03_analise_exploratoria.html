03. Análise exploratória dos registros por bioma

Jonathan David Castillo

2026-09-15

1 Riqueza de plantas nos biomas do Brasil

1.0.1 Objetivo

Nesta etapa, a matriz Br_01_clean2 é utilizada para explorar a distribuição temporal e espacial dos registros de ocorrência e para associá-los aos biomas brasileiros.

O procedimento é dividido em quatro partes principais:

  1. verificar a distribuição temporal dos registros;
  2. associar cada ocorrência a um bioma;
  3. avaliar a quantidade de registros e a riqueza observada por bioma;
  4. explorar a variação temporal da riqueza.

1.0.8 7. Padronizar o sistema de coordenadas

As ocorrências e os biomas são trabalhados no sistema WGS84, correspondente ao EPSG 4326.

biomas <- st_transform(
  biomas,
  crs = 4326
)

Br_01_analisis$bioma <- NA_character_

1.0.9 8. Associar as ocorrências aos biomas

Como a matriz pode conter um número muito grande de registros, a associação espacial é realizada em blocos de 500.000 registros. Isso reduz a quantidade de dados processada de uma única vez.

bloques <- split(
  seq_len(nrow(Br_01_analisis)),
  ceiling(seq_len(nrow(Br_01_analisis)) / 500000)
)

for (i in seq_along(bloques)) {

  ids <- bloques[[i]]

  pontos <- st_as_sf(
    Br_01_analisis[ids, ],
    coords = c("decimalLongitude", "decimalLatitude"),
    crs = 4326,
    remove = FALSE
  )

  resultado <- st_within(pontos, biomas)
  Br_01_analisis$bioma[ids] <- vapply(resultado, function(j) {
    if (length(j) == 1L) biomas$name_biome[j] else NA_character_
  }, character(1))

  rm(pontos, resultado)
  gc()

  cat(
    "Bloco", i, "de", length(bloques),
    "concluído\n"
  )
}

1.0.13 12. Reavaliar os registros sem bioma

Para os registros que permaneceram sem bioma, realizamos uma segunda associação espacial utilizando st_intersects().

resultado <- st_intersects(pontos_na, biomas)
# Fronteiras com mais de um bioma permanecem sem atribuição inequívoca.
Br_01_analisis$bioma[which(is.na(Br_01_analisis$bioma))] <-
  vapply(resultado, function(j) {
    if (length(j) == 1L) biomas$name_biome[j] else NA_character_
  }, character(1))

table(Br_01_analisis$bioma, useNA = "ifany")
