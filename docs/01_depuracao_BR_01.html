01. Depuração inicial de registros do GBIF

Jonathan David Castillo

15/09/2026

1 Objetivo

Esta etapa apresenta a depuração inicial da base Br_01, com foco na qualidade dos registros de ocorrência. O procedimento foi organizado para que cada decisão de limpeza possa ser acompanhada e, posteriormente, reproduzida.

A base original é mantida separada da base limpa. Além disso, é criada uma matriz de controle que registra o motivo pelo qual cada registro foi eliminado.

Importante: os arquivos de entrada e saída são considerados relativos à pasta principal do projeto. Por isso, não é utilizado setwd() com um caminho específico do computador.

Execução: esta página apresenta o procedimento original e um resumo verificado dos arquivos já produzidos. Os blocos de depuração ficam disponíveis para consulta. Para refazer os cálculos completos, configure as entradas locais e execute com params = list(reprocessar = TRUE). A geração padrão do site utiliza os resumos incluídos, sem repetir a leitura das bases de vários gigabytes.

1.6 7. Criar a matriz de controle da depuração

A matriz control_Br01 permite acompanhar cada registro da base original e registrar o primeiro motivo de eliminação identificado.

control_Br01 <- data.table(
  fila_original = seq_len(nrow(Br_01)),
  gbifID = if("gbifID" %in% names(Br_01))
    Br_01$gbifID else NA,
  occurrenceID = if("occurrenceID" %in% names(Br_01))
    Br_01$occurrenceID else NA_character_,
  motivo_eliminacao = NA_character_
)
registrar_eliminacion <- function(control, condicion, motivo){

  ids <- which(
    condicion &
    is.na(control$motivo_eliminacao)
  )

  if(length(ids) > 0){
    control$motivo_eliminacao[ids] <- motivo
  }

  return(control)
}

1.7 8. Registros sem latitude

Registros sem latitude não permitem uma análise espacial baseada em coordenadas.

if("decimalLatitude" %in% names(Br_01)){

  condicion <- is.na(Br_01$decimalLatitude)

  control_Br01 <- registrar_eliminacion(
    control_Br01,
    condicion,
    "Latitude ausente"
  )

}

1.8 9. Registros sem longitude

Da mesma forma, registros sem longitude não podem ser utilizados na análise espacial.

if("decimalLongitude" %in% names(Br_01)){

  condicion <- is.na(Br_01$decimalLongitude)

  control_Br01 <- registrar_eliminacion(
    control_Br01,
    condicion,
    "Longitude ausente"
  )

}

1.9 10. Eliminar coordenadas 0,0

A coordenada (0,0) é tratada como uma coordenada inválida para esta análise.

if(all(c(
  "decimalLatitude",
  "decimalLongitude"
) %in% names(Br_01))){

  condicion <-
    Br_01$decimalLatitude == 0 &
    Br_01$decimalLongitude == 0

  control_Br01 <- registrar_eliminacion(
    control_Br01,
    condicion,
    "Coordenada 0,0"
  )

}

1.10 11. Eliminar latitudes impossíveis

São identificados valores fora do intervalo geográfico possível de latitude.

if("decimalLatitude" %in% names(Br_01)){

  condicion <-
    !is.na(Br_01$decimalLatitude) &
    (
      Br_01$decimalLatitude < -90 |
      Br_01$decimalLatitude > 90
    )

  control_Br01 <- registrar_eliminacion(
    control_Br01,
    condicion,
    "Latitude fora do intervalo"
  )

}

1.11 12. Eliminar longitudes impossíveis

O mesmo procedimento é aplicado às longitudes.

if("decimalLongitude" %in% names(Br_01)){

  condicion <-
    !is.na(Br_01$decimalLongitude) &
    (
      Br_01$decimalLongitude < -180 |
      Br_01$decimalLongitude > 180
    )

  control_Br01 <- registrar_eliminacion(
    control_Br01,
    condicion,
    "Longitude fora do intervalo"
  )

}

1.12 13. Eliminar registros com status de ocorrência ausente

Registros cujo occurrenceStatus é igual a absent não representam uma ocorrência presente e, portanto, são marcados para exclusão.

if("occurrenceStatus" %in% names(Br_01)){

  condicion <-
    !is.na(Br_01$occurrenceStatus) &
    tolower(trimws(Br_01$occurrenceStatus)) == "absent"

  control_Br01 <- registrar_eliminacion(
    control_Br01,
    condicion,
    "Occurrence status = absent"
  )

}

1.13 14. Eliminar registros sem nome científico

Para as análises taxonômicas, é necessário que o registro possua um nome científico.

if("scientificName" %in% names(Br_01)){

  condicion <-
    is.na(Br_01$scientificName) |
    trimws(Br_01$scientificName) == ""

  control_Br01 <- registrar_eliminacion(
    control_Br01,
    condicion,
    "Nome científico ausente"
  )

}

1.14 15. Eliminar registros com nível taxonômico muito geral

São excluídos registros identificados apenas em níveis taxonômicos gerais.

if("taxonRank" %in% names(Br_01)){

  niveis_excluir <- c(
    "KINGDOM",
    "PHYLUM",
    "CLASS",
    "ORDER",
    "FAMILY"
  )

  condicion <-
    !is.na(Br_01$taxonRank) &
    toupper(trimws(Br_01$taxonRank)) %in% niveis_excluir

  control_Br01 <- registrar_eliminacion(
    control_Br01,
    condicion,
    "Nível taxonômico muito geral"
  )

}

1.17 18. Guardar os registros eliminados

Os registros eliminados são preservados em um arquivo separado. Isso permite verificar posteriormente o que foi removido sem alterar a base original.

linhas_eliminadas <- !is.na(
  control_Br01$motivo_eliminacao
)

Br_01_eliminados <- Br_01[linhas_eliminadas]

Br_01_eliminados[
  ,
  motivo_eliminacao :=
    control_Br01$motivo_eliminacao[
      linhas_eliminadas
    ]
]

1.23 24. Identificar coordenadas repetidas dentro da mesma espécie

Aqui não eliminamos os registros. Apenas identificamos registros que apresentam a mesma espécie e as mesmas coordenadas.

if(all(c(
  "scientificName",
  "decimalLatitude",
  "decimalLongitude"
) %in% names(Br_01_clean))){

  Br_01_clean[
    ,
    coord_taxon := paste(
      scientificName,
      decimalLatitude,
      decimalLongitude,
      sep = "_"
    )
  ]

  duplicados_coord_taxon <- Br_01_clean[
    duplicated(coord_taxon) |
    duplicated(coord_taxon, fromLast = TRUE)
  ]

    "\nRegistros com mesma espécie + coordenada:",
    nrow(duplicados_coord_taxon),
    "\n"
  )

}

1.24 25. Identificar registros com alta incerteza espacial

Registros com incerteza superior a 10 km são marcados, mas não são eliminados nesta etapa.

if("coordinateUncertaintyInMeters" %in% names(Br_01_clean)){

  Br_01_clean[

    incerteza_alta :=
      !is.na(coordinateUncertaintyInMeters) &
