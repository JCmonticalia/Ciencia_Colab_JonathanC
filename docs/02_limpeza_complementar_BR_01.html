Jonathan David Castillo

2026-09-08

1 Riqueza de plantas nos biomas do Brasil

1.0.1 Objetivo

Nesta etapa é realizada uma limpeza complementar da base produzida na etapa anterior. O foco está nos problemas identificados pelo GBIF, na localização dos registros dentro do Brasil e em alguns problemas taxonômicos.

O resultado principal é Br_01_clean2.csv, que será utilizado nas análises posteriores.

1.0.4 3. Verificar os problemas (issues) registrados pelo GBIF

issue_presentes <- Br_01[

1.0.5 4. Remover problemas considerados graves

A lista de exclusão do procedimento original foi preservada. A comparação agora exige códigos completos, separados por vírgula ou ponto e vírgula. Os códigos abreviados não são traduzidos automaticamente para os nomes extensos encontrados em exportações recentes do GBIF; ausência de correspondência não comprova ausência de problemas.

issues_graves <- c(
  "cdiv",
  "cdout",
  "cdrepf",
  "cdreps",
  "preneglat",
  "preneglon",
  "preswcd",
  "cdpi",
  "cdumi"
)

patron_issues <- paste(
  issues_graves,
  collapse = "|"
)

Br_01_clean2 <- Br_01[
  is.na(issue) |
  issue == "" |
  !grepl(
    paste0("(^|[;,])(", patron_issues, ")([;,]|$)"),
    issue
  )
]

cat(
  "Registros após revisar os issues:",
  nrow(Br_01_clean2),
  "\n"
)

1.0.6 5. Remover pontos localizados fora do Brasil

Como a análise está restrita ao Brasil, os registros com coordenadas são comparados com o polígono do país.

brasil <- rnaturalearth::ne_countries(

idx_coord <- which(
  !is.na(Br_01_clean2$decimalLatitude) &

pontos <- sf::st_as_sf(
  Br_01_clean2[idx_coord],

    "decimalLatitude"
  ),
  crs = 4326,
  remove = FALSE
)

dentro <- sf::st_within(
  pontos,

1.0.10 9. Mapa das ocorrências

O mapa apresenta uma amostra de até 150 mil registros após a limpeza complementar; a matriz salva conserva todos os registros retidos.

library(sf)
library(ggplot2)
library(rnaturalearth)
library(geobr)
library(ggspatial)


brasil <- ne_countries(
  country = "Brazil",
  scale = "medium",
  returnclass = "sf"
)

# Estados de Brasil

estados <- geobr::read_state(year = 2020, simplified = TRUE)

# Amostra reprodutível apenas para visualização
set.seed(123)
ocorrencias_sf <- st_as_sf(
  dplyr::slice_sample(Br_01_clean2, n = min(150000, nrow(Br_01_clean2))),
  coords = c("decimalLongitude", "decimalLatitude"),
  crs = 4326,
  remove = FALSE
)

# Mapa
ggplot() +
  geom_sf(
    data = brasil,
